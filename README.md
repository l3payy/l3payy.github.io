# Portfolio — frosted glass carousel

Полноэкранная страница: фоновая картинка (`bg/sun.jpg`, оптимизирована до 3000×2000, ~1.1 МБ), сверху по центру — заголовок **«Привет, я Дима»** (Google Font **Unbounded Bold**, 48px, белый, отступ 28px от верха) и под ним через 8px подзаголовок (Unbounded Medium 14px, белый, 60%), а также 11 карточек 440×345 в горизонтальном ряду с промежутком `16px`. Фон затемнён чёрным на 14%. Ряд уходит за оба края экрана: при свайпе или прокрутке колесом карточки прячутся за край и появляются с другой стороны. Первые две карточки — с картинками (`aukus5.png` и `sport.webp`) и ведут на Behance: клик по соседней карточке сначала центрирует её, клик по центральной открывает ссылку. У кликабельных карточек курсор-указатель. Остальные карточки пустые, перетаскивание прокручивает ряд.

Стекло простое: класс `.glass-effect` — Fill `#E3E3E3` 20%, Inner shadow `#FFFFFF` 40% (Blur 14, Spread 0), Stroke Center 4px `#FFFFFF` 8% и `backdrop-filter: blur(6px)`. WebGL-библиотека LiquidGlass удалена.

## Запуск

```bash
python -m http.server 4173
```

и открыть `http://127.0.0.1:4173/`.

## Как это двигается

- горизонтальный ряд с промежутком `16px` — карточки не пересекаются;
- центральная карточка крупная, а дальние от центра сильно уменьшаются (эффект глубины, минимум `0.58`);
- карточки очень медленно и чуть-чуть покачиваются вверх-вниз (амплитуда `6px`);
- ряд бесконечный: при свайпе карточки уходят за край экрана и появляются с другой стороны;
- прокрутка плавная: позиция каждый кадр «догоняет» цель, поэтому и перетаскивание, и доводка идут мягко;
- после отпускания — инерция (до 1 карточки) и плавная доводка;
- колесо мыши/трекпад тоже прокручивает ряд;
- стрелки ← → на клавиатуре переключают на одну карточку.

## Размеры

- карточка — `440 × 345px`, скругление `28px`;
- обводка — 4px по центру (2px внутрь + 2px наружу), 8% белого;
- картинка внутри — с отступом `8px` (424 × 329px) и скруглением `22px`;
- наклон — случайный при каждой загрузке страницы, от −7° до +7° (0 исключён);
- всего карточек — 10 (1 с картинкой + 9 пустых).

## Стандартный эффект

Единый «эффект» для всех прозрачных карточек (и для будущих элементов) — класс `.glass-effect` в `css/style.css`:

- **Fill** — `#E3E3E3`, 20%;
- **Inner shadow** — X 0, Y 0, Blur 14, Spread 0, `#FFFFFF`, 40%;
- **Stroke** — Center, 4px, `#FFFFFF`, 8%;
- **Blur** — 6px.

Чтобы применить его к новому элементу, просто добавь ему класс `glass-effect`.

## Погода

Внизу справа (28px от права и низа) — виджет погоды в Москве: плашка `240×55`, скругление `24px`, тот же glass-эффект, что у карточек, случайный наклон −5…+5° при загрузке. Внутри: иконка `39×39` из `weatherIcon/`, справа блок текста — «Москва» с `point.svg` (10px SemiBold, 50%) и состояние погоды (20px Bold, белый).

Данные берутся из [Open-Meteo](https://open-meteo.com/) (бесплатно, без API-ключа). По коду погоды выбирается иконка и фон:

- ясно / почти ясно → `sun.svg`, `sun.jpg`
- облачно / туман → `cloud.svg`, `cloud.jpg`
- дождь / ливень / гроза → `rain.svg`, `rain.jpg`
- снег / снегопад → `snow.svg`, `snow.jpg`

Если API недоступен, виджет показывает «Нет данных», а фон остаётся текущим.

## Файлы

- `index.html` — сцена и фон;
- `css/style.css` — фон, карточки и их backdrop blur;
- `js/carousel.js` — карточки, ряд и движение;
- `js/weather.js` — погода в Москве и выбор фона;
- `bg/` — фоны: `sun.jpg` (3000×2000, ~1.1 МБ), `cloud.jpg`, `rain.jpg`, `snow.jpg` (2528×1684, ~0.4 МБ каждый);
- `cardImages/aukus5.png`, `cardImages/sport.webp` — картинки кликабельных карточек;
- `weatherIcon/` — иконки погоды (`sun.svg`, `cloud.svg`, `rain.svg`, `snow.svg`, `point.svg`).

## Что менять

- **Фон** — `src` у `<img class="bg">` в `index.html`. Если заменил файл с тем же именем, подними `?v=` у него, иначе браузер покажет старый из кэша.
- **Заголовок и подзаголовок** — текст в `.hero-title` / `.hero-subtitle` в `index.html`; шрифт, размер и цвет — в `css/style.css`.
- **Стандартный эффект** — класс `.glass-effect` в `css/style.css` (Fill, Inner shadow, Stroke, Blur).
- **Картинки карточек** — массив `CARDS` в `js/carousel.js`: `image`, `alt`, `href` (если `href` есть — карточка кликабельна).
- **Промежуток между карточками** — `GAP` в `js/carousel.js`.
- **Плавность прокрутки** — `SMOOTH` в `js/carousel.js` (меньше = плавнее/инертнее, больше = отзывчивее).
- **Чувствительность колеса** — `WHEEL_STEP` (сколько дельты колеса на одну карточку) и `WHEEL_GAP` (пауза между шагами) в `js/carousel.js`.
- **Инерция / перескок** — `TOSS` и `MOST`.
- **Уменьшение по краям** — `MIN_SCALE` и `SCALE_FALLOFF`.
- **Наклон** — диапазон в `randomTilt()`; соседние карточки всегда отличаются минимум на `2°` (`MIN_TILT_GAP`).
- **Покачивание** — `BOB_AMPLITUDE` (амплитуда в px) и `BOB_PERIODS` (периоды) в `js/carousel.js`.

При изменении `css/style.css` или `js/carousel.js` подними `?v=` в `index.html`, чтобы браузер не взял старую версию из кэша.
